# Лабораторна робота 5
**Тема:** Застосування алгоритму пошуку в ширину (BFS).
**Рівень 2**
**Варіант:** 3 (Пошук мінімальної глибини бінарного дерева).

## Опис задачі
Дано двійкове дерево, подане у вигляді списку суміжності. Необхідно знайти його мінімальну глибину - загальну кількість вузлів уздовж найкоротшого шляху від кореневого вузла до найближчого кінцевого вузла (листка).
