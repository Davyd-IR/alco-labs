# Лабораторна робота 6
**Тема:** Динамічне програмування.
**Рівень:** 2
**Варіант:** 2 (Кар'єра/Career).

## Опис задачі
Організаційна структура компанії має форму піраміди. Кожна посада приносить певну кількість досвіду. Необхідно визначити максимальну суму досвіду, яку можна здобути, рухаючись від найнижчого рівня до вершини.

## Реалізація
- Алгоритм: Динамічне програмування (підхід "знизу-вгору").
- Вхідні дані: файл 'career.in'.
- Вихідні дані: файл 'career.out'.
- Юніт-тести: реалізовано з використанням бібліотеки 'unittest'.
